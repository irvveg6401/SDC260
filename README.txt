Website Purpose

SBR Clothing is an e-commerce website concept that sells casual clothing, including T-shirts, hoodies, jeans, pants, jackets, and accessories. The website will allow customers to browse products, view product details, add items to a shopping cart, and complete the checkout process.

The goal is to create a simple, user-friendly website with a modern design that works on computers and mobile devices.

Planned Feature Roadmap

 Week 1  Project Setup. Create the GitHub repository, design the website layout, and create the initial HTML page.       20 hours       
 Week 2  Homepage and Products. Build the homepage, product categories, and product cards.                                25 hours       
 Week 3  Product Details and Shopping Cart  Add product information, size and color options, and shopping cart functionality. 30 hours       
 Week 4  Checkout and Testing. Create the checkout page, test the website, fix issues, and prepare it for launch.         35 hours
